# Git vs SVN

1. Почему в Git ветки дешёвые, а в SVN дорогие?
В Git ветка это просто ссылка на коммит, весит почти ничего и создаётся мгновенно. В SVN ветка — это реально скопированная папка на сервере, поэтому дольше и место жрёт.

2. Можно в SVN коммитить без интернета?
Нет, там нет локального репозитория с историей — только один центральный сервер. Без сети коммит просто некуда отправить.

3. Когда SVN всё ещё может быть лучше?
Там, где уже давно всё построено на SVN и переезжать дорого/страшно — например старые системы в банках или госструктурах. Для новых проектов смысла в нём нет.
